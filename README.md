# Lasyankali ERP

AI Powered Dance Academy ERP for Bharatanatyam Institutions.

## Tech Stack

- Java 21
- Spring Boot 3
- Spring Security JWT
- MySQL
- React
- Tailwind CSS
- Razorpay
- OpenAI API

## Modules

- Authentication
- Student Management
- Parent Management
- Teacher Management
- Batch Management
- Attendance Management
- Examination Management
- Event Management
- Fee Management
- AI Dance Guru
- AI Examination Coach
- AI Choreographer
